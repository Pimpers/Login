# 📱 Login — Smart App Challenge 2022 준비작 (Android)

> 중소벤처기업부와 SK Planet에서 주최하는 **Smart App Challenge 2022** 대회 준비작품입니다. (제작 중에 멈춘 프로젝트)

| | |
|---|---|
| **내 파트** | **로그인 · 회원가입** |
| **언어 / 플랫폼** | Java, Android (Android Studio, Gradle) |
| **사용 기술** | Firebase Authentication, Firebase Realtime Database, Volley |

## 구현한 것
- `Loginactivity` — Firebase Auth 이메일 로그인
- `RegisteActivity`, `UserAccount` — 회원가입 화면과 사용자 계정 모델을 Realtime Database에 저장
- `MainActivity` — 하단 메뉴 내비게이션 + 홈 / 라이브 / 리뷰 / 날씨 / 설정 / 더보기 6개 Fragment 화면 틀

## 상태
대회 준비 중 제작이 중단되어 **로그인·회원가입 파트와 화면 구조까지만** 구현되어 있습니다.

## 관련 프로젝트
**외부 서비스(Firebase)를 앱에 연동**한 프로젝트입니다. 완성도 있는 최근 결과물은 [고양이 용병단](https://github.com/Pimpers/team)입니다.
